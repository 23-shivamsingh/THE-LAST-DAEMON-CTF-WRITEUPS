- **OSINT (3):** The Silent Broadcaster (300 pts), The Shadow Syndicate (500 pts), Blackwood Trail (500 pts)
- **Pwn (4):** Format Matrix & Heap Echo (300 pts), Return Oriented Academy (300 pts), Jailbreak Arena (500 pts), Allocator's Scar (500 pts)
- **Reverse Engineering (2):** The Debug Log (100 pts), Silicon Phantom (500 pts)
- **Web (2):** Proxy Impersonator (500 pts), Object Pollution Protocol (500 pts)
- **Miscellaneous (2):** Polyglot Sanctuary (300 pts), Radio Wire (500 pts)
